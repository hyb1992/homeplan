# 우리집 매수계획

보유 자금, 매수 일정, 대출과 생활비를 일별로 계산하는 로컬 앱입니다. SQLite가 기준 저장소이며 엑셀은 가져오기 용도로만 사용합니다.

## 바로 사용하기

- 웹: https://hyb1992.github.io/homeplan/
- Windows 앱: https://github.com/hyb1992/homeplan/releases/latest/download/HomePlan-Windows-x64.zip

웹은 Python을 브라우저 안에서 실행하고 SQLite를 IndexedDB에 보관합니다. 금융 입력은 서버에 전송하지 않습니다. 첫 실행에는 계산 환경을 다운로드하므로 인터넷이 필요합니다. 브라우저의 사이트 데이터를 삭제하면 저장한 계획도 지워집니다. 입력값 내보내기로 별도 보관하세요. Windows·다른 기기·다른 브라우저와 자동 동기화하지 않으며 JSON으로 옮길 수 있습니다.

Windows는 ZIP 전체를 새 폴더에 풀고 `HomePlan/HomePlan.exe`를 실행합니다. Python 설치 없이 사용할 수 있고 새 버전을 실행할 때 자동으로 확인합니다. 최초 계획은 비어 있으며 예시는 별도의 가상 테스트입니다.

## Windows에서 시작

Python 환경 관리 도구 [uv](https://docs.astral.sh/uv/getting-started/installation/)를 설치한 뒤 프로젝트 폴더에서 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\setup_local.ps1
```

바탕화면의 우리집 매수계획을 열고 **새 계획**에서 본인의 현금·소득·생활비와 매수 일정을 입력합니다. 가상 데이터는 예시 체험용입니다. 상세 설정에서 수리비, 세금, 출산휴가·육아휴직·복직, 소득 보전 조건을 확인하세요.

## 계산 시작과 보유금

새 계획은 한국 시간 오늘부터 보여줍니다. 보유 자금 기준일은 금액을 확인한 날입니다. 앱은 그 기준일의 자산과 입력한 과거 계획을 계산해 오늘의 시작 현금을 이어받습니다. 이는 은행 실제 잔액의 자동 조회가 아닙니다. 현재 잔액이 다르면 자산 기준일과 자금 항목을 함께 갱신하세요.

계산 결과 카드를 누르면 해당 날짜의 입출금과 부채를 볼 수 있습니다. 월 지출 초과 옆의 지출 내역은 문제가 되는 달로 이동합니다. 월 유지비에는 연 비용·보유세 월평균이 포함되며, 실제 납부와 일회성 비용은 날짜별 원장에 반영됩니다.

지출 금액 변경은 기존 항목의 **금액 변경**에서 설정합니다. 대출 추가 상환은 날짜·원금·수수료·납입 감소 또는 기간 단축을 선택합니다. 은행 약정 조건에 맞게 입력하세요. 비교할 계획은 복사해 다른 이름으로 저장할 수 있습니다.

## 저장과 복구

변경사항 저장은 계산 미리보기와 확인 후 보관됩니다. 저장 기록에서 이전 입력을 복원할 수 있습니다. 미저장 초안은 이 브라우저에 임시 보관되며 다시 열 때 복구할 수 있습니다. 저장본과 충돌하면 새 계획으로 복사해 복구합니다.

백업·복구에서 독립 SQLite 백업과 저장 폴더를 선택합니다. 기본 자동 백업은 `data/backups`이며 하루 첫 실행·저장 때 생성됩니다. 백업 내용 확인 후 현재 선택한 계획만 복구하고 다른 계획은 보존합니다. 디스크 장애 대비에는 백업 폴더를 다른 드라이브로 지정하세요. JSON 내보내기·가져오기도 지원합니다.

## 업데이트

웹은 저장 후 새로고침하면 GitHub의 최신 배포를 사용합니다. 새 배포가 확인되면 화면에 안내합니다. 저장 DB는 웹 코드 배포와 별개로 이 브라우저에 유지됩니다.

Windows 배포본은 앱 창을 닫고 약 90초 후 다시 실행하면 최신 릴리스를 확인해 별도 버전 폴더에 설치합니다. 사용 중인 앱은 중단하지 않습니다. DB·프로필은 기존 `data`에 유지하고 버전 적용 전 백업을 만듭니다. 다운로드나 새 버전 실행에 실패하면 이전 버전으로 열립니다. 인터넷이 없어도 설치된 버전을 사용할 수 있습니다. 이미 받은 0.3 배포본은 자동 업데이트 기능이 없으므로 0.4 이후 ZIP을 처음 한 번 받아야 합니다. 개발용 소스 폴더는 자동 교체하지 않습니다.

소스로 실행하는 개발자는 편집을 먼저 저장한 뒤 새 소스 파일을 적용하고 아래 명령을 실행합니다. `data` 폴더를 유지하세요.

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\setup_local.ps1 -Update
```

업데이트는 DB 백업, 이 앱의 서버 확인·종료, 환경 동기화, 검증, 실행 순서로 진행합니다. 앱은 127.0.0.1에서 실행합니다. 외부 공유 서버용 인증과 가구별 권한은 별도 배포 단계입니다.

## 개발 검증

```powershell
uv run ruff check .
uv run ruff format --check .
uv run mypy src/homeplan
uv run pytest -q
node --test tests/web/test_form_inputs.mjs
uv run python tools/check_web_upgrade.py
```

브라우저 검증은 독립 가상 DB와 임시 서버를 생성하고 종료합니다. Windows에서는 Edge를 사용합니다. 다른 환경에서는 Playwright Chromium 설치가 필요합니다. 실제 가구 데이터와 개인 golden은 포함하지 않습니다. 금융 규칙의 적용 범위·출처·확인일은 앱의 계산 기준·출처에서 확인하세요.

## 자동 배포 운영

`main`에 push하면 GitHub Actions가 정적 검사·타입 검사·단위 테스트·브라우저 검증 후 GitHub Pages를 게시하고 Windows x64 ZIP과 SHA-256 매니페스트를 Releases에 올립니다. 실패한 빌드는 게시하지 않습니다. 앱 업데이트는 이 저장소의 최신 정식 릴리스를 사용합니다. 별도 배포 토큰은 코드나 앱에 포함하지 않습니다.

Pages는 저장소 Settings → Pages에서 GitHub Actions를 소스로 사용합니다. PR은 CI만 실행하고 배포하지 않습니다. 개인 DB·백업·엑셀·내보내기·개인 검토 자료는 커밋하거나 릴리스에 첨부하지 마세요.

## 개인 자료 없이 다른 사람에게 전달

Windows 전달 ZIP은 별도로 빌드합니다. 실행 환경이 포함되므로 받는 사람은 Python을 설치할 필요가 없습니다.

```powershell
uv run --group build python tools/build_friend_package.py
```

생성된 ZIP 전체를 전달하고, 받는 사람은 새 폴더에 압축을 풀어 `HomePlan/HomePlan.exe`를 실행합니다. 첫 실행은 금액 0원의 새 사용자 계획에서 시작하며 본인의 계획 입력창이 열립니다. 재실행 때는 입력이 유지됩니다.

빌드는 공개 화면·규칙·가상 예시만 모읍니다. 현재 PC의 DB·백업·브라우저 프로필과 개인 문서는 포함하지 않습니다. 실행 후 `data`가 생긴 폴더 대신 처음 만든 전달 ZIP을 공유하세요. ZIP은 다음 명령으로 별도 폴더에서 실행·저장·재실행 검증할 수 있습니다.

```powershell
uv run --group build python tools/check_friend_package.py "dist/전달용.zip"
```
